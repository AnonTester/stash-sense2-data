# stash-sense2-data

Face recognition database + model releases for stash-sense2 (buffalo_l +
usearch migration, testing). Separate from `stash-sense-data` (v1) --
the release format here is not compatible with v1's database_updater.py.

Not meant to be browsed directly -- see the Releases page for downloadable
assets (performer database, ONNX models).
